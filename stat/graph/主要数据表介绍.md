# main_enriched.parquet 数据字典

## 📊 文件概览

- **位置**: `stat/graph/main_enriched.parquet`
- **行数**: 5,092,683 条（专利记录）
- **列数**: 23 列
- **生成过程**: 
  1. 主来源（`main.parquet`）：来自 `patent_quality_output.csv`
  2. 通过左连接添加发明授权类专利的额外信息（`extra_all_dedup.parquet`）
  3. 只保留**发明授权**类型的专利，并进行了重复处理

---

## 🗂️ 列说明

### 一、核心标识

| 列名 | 数据类型 | 说明 |
|------|--------|------|
| **申请号** | String | 专利申请号（唯一标识，如 `CN85106332.2`） |

### 二、时间维度

| 列名 | 数据类型 | 说明 |
|------|--------|------|
| **申请年份** | Int64 | 专利申请的年份（如 1985） |
| **公开公告年份** | String | 专利公开或公告的年份 |

### 三、专利基本信息

| 列名 | 数据类型 | 说明 |
|------|--------|------|
| **专利名称** | String | 专利的官方名称 |
| **专利类型** | String | 专利类型（该表中均为"发明授权"） |
| **IPC主分类号** | String | 国际专利分类号主分类 |

### 四、权利人信息

| 列名 | 数据类型 | 说明 |
|------|--------|------|
| **申请人** | String | 专利权申请人/申请单位 |
| **申请人类型** | String | 申请人类型（如：企业、个人、学校等） |
| **申请人地址** | String | 申请人注册地址 |
| **申请人城市** | String | 申请人所在城市 |
| **专利权人类型** | String | 专利权人类型分类 |
| **统一社会信用代码** | String | 申请人的统一社会信用代码（用于关联企业数据） |

### 五、专利质量指标

| 列名 | 数据类型 | 说明 |
|------|--------|------|
| **BS** | Float64 | 专利质量评分（Backward Similarity，向后引用相似度） |
| **FS** | Float64 | 专利质量评分（Forward Similarity，向前引用相似度） |
| **Quality_q** | Float64 | 综合质量指标（质量评分） |

### 六、引证指标

这 8 列用于评估专利的影响力和创新程度：

| 列名 | 数据类型 | 说明 |
|------|--------|------|
| **引证次数** | Int64 | 该专利被引用的**总次数** |
| **被引证次数** | Int64 | 该专利被其他专利引用的**总次数**（同被引证次数） |
| **自引次数** | Int64 | 该专利权人**自己引用**该专利的次数 |
| **他引次数** | Int64 | **其他权利人**引用该专利的次数 |
| **被自引次数** | Int64 | 该专利权人**自己的其他专利**引用该专利的次数 |
| **被他引次数** | Int64 | **其他权利人的专利**引用该专利的次数 |
| **家族引证次数** | Int64 | 该专利**引用其家族专利**的次数（国际专利家族） |
| **家族被引证次数** | Int64 | 该专利**被自己的家族专利引用**的次数 |

## 📈 数据特征

### 数值缺失（Null 值）

- **引证相关列**：某些专利可能的引证数据为 null（表示无该类引证或数据缺失）
- 从附表截图可看出：例如 `被自引次数` 和 `家族引证次数` 在某些行为 null

### 质量指标

- **BS、FS、Quality_q**：均为浮点数，表示不同维度的专利质量评分
- 从示例看，这些值通常在 0.0 ~ 1.0 之间

### 数据覆盖范围

- **年份范围**：从 1985 年起（可从 `申请年份 = 1985` 看出）
- **总记录数**：509 万+ 条，涵盖中国40多年的发明授权专利

---

## 🔗 数据关联

### 可用于连接的关键字段

- **统一社会信用代码**：可与上市公司财务数据关联
  - 连接表：`stat/公司财务/数据/上市公司（包括所有子公司）各年度的统一社会信用代码列表.csv`
  
- **申请年份**：可用于时间维度的分析

- **IPC主分类号**：可用于行业/技术领域分析

---

## 💡 使用场景示例

1. **按企业统计专利**: 筛选特定 `统一社会信用代码`，统计该企业历年专利数、被引情况
2. **质量分析**: 使用 BS、FS、Quality_q 评估专利质量
3. **影响力评估**: 使用 `被他引次数` 衡量专利被业界采纳程度
4. **创新能力分析**: 结合 `申请年份` 和 `被引证次数` 进行时间序列分析
5. **行业对标**: 按 `IPC主分类号` 进行同行业专利对比
