# 数据表格结构总结（包含路径）

## 1️⃣ **上市公司统一社会信用代码.csv**

### 位置：

```
stat/公司财务/数据/上市公司基本信息年度表/上市公司统一社会信用代码.csv
```

### 结构：

- **列**：
  1. `stkid`：股票代码（证券ID）
  2. `shortname`：公司简称
  3. `SocialCreditCode`：统一社会信用代码
  4. `FirstYear`：最早的年份（公司首次上市年份）
  5. `LastYear`：最晚的年份（公司最新的数据年份）

### 含义：

- 该表提供了每家上市公司（按 `stkid` 唯一标识）的基本信息。
- 包含 **每家公司首次出现的年份** 和 **最后一年的数据**，用于后续按年份进行数据补齐。

### 示例：

```
stkid | shortname | SocialCreditCode | FirstYear | LastYear
000001 | 平安银行 | 91440300192185379H | 2000 | 2025
000002 | 万科A    | 91440300192201076Y | 2001 | 2025
...
```

### 用途：

- **作为母公司信息的来源**，用于后续拼接子公司信息（`stkid` 可以用来做 `join`）。

---

## 2️⃣ **上市公司子公司对应统一社会信用代码.csv**

### 位置：

```
stat/公司财务/数据/爱企查数据/上市公司子公司对应统一社会信用代码.csv
```

### 结构：

- **列**：
  1. `企业名称`：子公司或关联公司的名称
  2. `统一社会信用代码`：子公司或关联公司的统一社会信用代码

### 含义：

- 该表是从爱企查平台提取的 **子公司与其对应的统一社会信用代码** 数据。
- 一个**公司名称**可以对应多个 **统一社会信用代码**，这通常表示：
  - 同一个名称对应不同的法人、主体、注册号等情况。
  - 数据可能存在重复的公司名称（例如同名企业注销再注册，或同集团的多家不同法人）。

### 示例：

```
企业名称         | 统一社会信用代码
平安银行子公司    | 91440300192185379H
万科A子公司       | 91440300192201076Y
...
```

### 用途：

- 用于从 **公司名称**（`RalatedParty`）匹配到**统一社会信用代码**，并通过映射关系进行子公司数据的拼接。
- 你已经处理了同名不同代码的情况，通过拼接的方式将多个代码合并成一个列表，以便后续使用。

---

## 3️⃣ **STK_NotesSubJoint_merged.csv** （子公司联营合营关系表）

### 位置：

```
stat/公司财务/数据/上市公司子公司联营合营情况表/STK_NotesSubJoint_merged.csv
```

### 结构：

- **列**：
  1. `Symbol`：证券代码（母公司）
  2. `EndDate`：统计日期（年）
  3. `RalatedParty`：关联公司名称（子公司名称）
  4. `Relationship`：母子公司关系（如子公司、联营公司、合营公司等）

### 含义：

- 该表记录了每个母公司与其子公司、联营、合营公司的关联信息。
- **每个 `Symbol`**（母公司）可能有多个不同的 `RalatedParty`（子公司或关联公司）。
- 需要注意的是，表中的 `Relationship` 可能包含多个关系类型（如子公司、联营等）。

### 示例：

```
Symbol  | EndDate   | RalatedParty    | Relationship
000001  | 2000/12/31| 平安银行子公司  | 子公司
000001  | 2001/12/31| 万科A子公司     | 联营公司
...
```

### 用途：

- 用于**找到每个母公司（`Symbol`）的所有子公司**（`RalatedParty`），
- 按 `EndDate` 确定哪些子公司属于哪一年，进而为每一年汇总该母公司的所有子公司及其对应的**统一社会信用代码**（通过 `上市公司子公司对应统一社会信用代码.csv` 进行映射）。

---

## 4️⃣ **上市公司（包括所有子公司）各年度的统一社会信用代码列表.csv**（输出目标）

### 位置：

```
stat/公司财务/数据/上市公司（包括所有子公司）各年度的统一社会信用代码列表.csv
```

### 结构：

- **列**：
  1. `证券ID`（`stkid`）：股票代码
  2. `公司简称`（`shortname`）：公司简称
  3. `年份`（`year`）：统计的年份
  4. `统一社会信用代码列表`：该公司（包括子公司）在该年份的**统一社会信用代码**（用分号 `;` 拼接）

### 含义：

- 这张表输出了每个母公司在每一年的所有**统一社会信用代码**，不仅仅是母公司代码，还包括所有子公司、联营、合营公司代码。
- 子公司数据是**基于 STK_NotesSubJoint_merged.csv** 与 **上市公司子公司对应统一社会信用代码.csv** 进行拼接的。

### 示例：

```
证券ID  | 公司简称  | 年份 | 统一社会信用代码列表
000001 | 平安银行  | 2000 | 91440300192185379H;91440300192201076Y
000001 | 平安银行  | 2001 | 91440300192185379H;91440300192201076Y;91440300192300337B
...
```

### 用途：

- 用于后续的**数据整合、回归分析**，例如按年度统计专利得分时，使用 **统一社会信用代码列表** 作为连接条件，**将母公司与子公司的专利数据**进行结合。
- 提供了母公司与所有子公司关联的信用代码，以便进行各类跨公司的数据整合。
