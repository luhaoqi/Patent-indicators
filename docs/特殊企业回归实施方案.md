# 特殊企业回归实施方案

本文档用于后续实施“特殊企业 vs 非特殊企业”相关回归改造。目标是把当前以分组统计和样本 t 检验为主的比较，扩展为一套能控制年份差异、并区分静态与动态口径的回归框架。

## 1. 设计原则

- 当前直接比较 `Quality_q` 均值，会混入年份间质量水平和尺度变化。
- 因此后续回归同时区分：
  - 原始质量 `Quality_q`
  - 年内标准化质量
  - 年内前 `k%` 高质量专利指标
- 自变量同时区分：
  - `ever_special_f`：公司是否曾经成为过特殊企业
  - `special_year_ft`：公司在年份 `t` 是否为特殊企业
- 样本单位区分为：
  - 专利层：单条样本是一件专利
  - 公司-年份层：单条样本是一个公司在一个年份的聚合结果

## 2. 变量定义

下标约定：

- `p`：专利
- `f`：公司 / UCC
- `t`：年份

基础变量：

- `raw_q_pft`：专利原始 `Quality_q`
- `z_q_pft`：专利在年份 `t` 内的标准化质量（z-score）
- `rank_q_pft`：专利在年份 `t` 内的相对排名，定义为 `rank / total_patents_t`
- `topk_q_pft`：专利是否进入年份 `t` 内前 `k%`
- `ever_special_f`：公司是否曾经成为过特殊企业，取值 `0/1`
- `special_year_ft`：公司在年份 `t` 是否为特殊企业，取值 `0/1`

其中：

- `z_q_pft = (raw_q_pft - mean_t(raw_q)) / sd_t(raw_q)`，即在每个年份内分别做 z-score 标准化。
- `rank_q_pft` 越小越好。
- `topk_q_pft = 1{rank_q_pft <= k}`。
- 默认 `k = 0.10`，表示年度前 10%。
- 实施时建议在每个年份内按 `raw_q_pft` 降序排序；若出现同分，需固定稳定的打破平局规则，建议使用 `申请号` 升序。

三组解释口径：

- `A` 组：`ever_special_f = 1` 且 `special_year_ft = 1`
- `B` 组：`ever_special_f = 1` 且 `special_year_ft = 0`
- `C` 组：`ever_special_f = 0`，此时必有 `special_year_ft = 0`

公司-年份层聚合变量：

- `patent_count_ft`：公司 `f` 在年份 `t` 的专利总数
- `highq_count_ft`：公司 `f` 在年份 `t` 的高质量专利数，定义为 `sum_p(topk_q_pft)`
- `mean_raw_q_ft`：公司 `f` 在年份 `t` 的原始质量均值
- `mean_z_q_ft`：公司 `f` 在年份 `t` 的标准化质量均值
- `highq_share_ft`：公司 `f` 在年份 `t` 的高质量专利占比，定义为 `highq_count_ft / patent_count_ft`
- `log_patent_count_ft`：`log(1 + patent_count_ft)`
- `log_highq_count_ft`：`log(1 + highq_count_ft)`

## 3. 方法细节

### 3.1 年内标准化

- `z_q_pft` 使用年份内 z-score 标准化，目的是消化跨年质量分布尺度变化。
- `topk_q_pft` 使用年份内相对排名，目的是避免固定阈值（如 `Quality_q >= 1`）受年份分布变化影响。

### 3.2 年份固定效应

- `year FE` 用于在同一年内部比较特殊企业与非特殊企业。
- 即便使用了年内标准化或年内前 `k%` 指标，仍然保留 `year FE`，因为标准化解决的是因变量可比性，年份固定效应解决的是比较发生在哪个年份内部。

### 3.3 公司固定效应

- `firm FE` 只与 `special_year_ft` 搭配使用。
- `ever_special_f` 在公司内不随时间变化，和 `firm FE` 同时出现会被完全吸收，因此不做：
  - `... ~ ever_special_f + firm FE + year FE`

### 3.4 A/B/C 分解回归

- 为了区分：
  - `A-B`：特殊企业处于特殊年份，相对这些企业的非特殊年份
  - `B-C`：曾经成为特殊企业的企业在非特殊年份，相对从未成为特殊企业的企业
  - `A-C`：特殊企业处于特殊年份，相对从未成为特殊企业的企业
- 单独做：
  - `y_ft ~ special_year_ft + year FE`
  会把 `B` 和 `C` 混成一个基准组，解释不够清楚。
- 因此不加公司固定效应的动态比较，统一使用：
  - `y_ft ~ ever_special_f + special_year_ft + year FE`
- 在该规格下：
  - `ever_special_f` 的系数对应 `B-C`
  - `special_year_ft` 的系数对应 `A-B`
  - 两个系数之和对应 `A-C`

### 3.5 加权

- 对公司-年份层的均值/占比回归，使用：
  - `weight = patent_count_ft`
- 适用对象：
  - `mean_raw_q_ft`
  - `mean_z_q_ft`
  - `highq_share_ft`
- 含义：
  - 一个仅有 1 件专利的 `firm-year`，不应和有 100 件专利的 `firm-year` 拥有同样的信息量。
- 在实现上，加权不改变方程形式，改变的是拟合目标：从等权最小二乘变为按 `patent_count_ft` 加权的最小二乘。

### 3.6 聚类标准误

- 所有回归至少使用：
  - `SE clustered by firm`
- 含义：
  - 同一公司跨年观测、同一公司名下多件专利的误差项通常相关，不能视为完全独立样本。
- 如果不聚类，标准误通常会偏小，显著性容易被高估。

### 3.7 双版本标准误输出

- 为了方便比较显著性变化，每一个回归都同时输出两套推断结果：
  - `cluster_firm`：按公司 `UCC` 聚类标准误
  - `no_cluster`：不按公司聚类，使用常规非聚类标准误
- 其中：
  - `cluster_firm` 是主版本，用于正式结论
  - `no_cluster` 仅作为对照版本，用于比较“聚类前后显著性变化”，不能替代主版本
- 因此，下文每个回归即使在“方法”一栏中写“标准误按公司聚类：是”，也默认还会同时输出一个 `no_cluster` 对照结果。

## 4. 最终实施的回归

- 方程：
  - `raw_q_pft ~ ever_special_f + year FE`

  - 年内标准化：否
  - 年内 top-k：是
  - 年份固定效应：是
  - 公司固定效应：是
  - `patent_count_ft` 加权：否
  - 标准误按公司聚类：是
- 备注：
  - 该规格是动态高质量产出主结果之一。

## 6. 暂不单独实施的重复规格

以下规格暂不单独实施：

- `mean_raw_q_ft ~ ever_special_f + year FE`
- `mean_z_q_ft ~ ever_special_f + year FE`
- `highq_share_ft ~ ever_special_f + year FE`
- `y_ft ~ special_year_ft + year FE`

原因：

- 当解释变量只在公司层变化，且公司-年份层均值/占比回归使用 `weight = patent_count_ft` 时，它们与对应的专利层静态回归在识别含义上高度接近。
- 因此默认保留专利层静态规格，避免输出重复结果。
- 对于不加公司固定效应的动态比较，若仅写成 `y_ft ~ special_year_ft + year FE`，会把 `B` 组和 `C` 组混成一个基准组，解释不清晰，因此统一改为 `y_ft ~ ever_special_f + special_year_ft + year FE`。

## 7. 输出目录规范

所有回归结果都输出到对应实验目录下的：

   - `cluster_firm`

## 8. 实施注意事项

- 年内排名与前 `k%` 的构造必须固定同分处理规则，避免重复运行时结果不稳定。
- `k` 必须参数化，不写死为 `10%`，默认值可设为 `0.10`。
- `topk_q_pft` 建议作为参数化衍生变量统一生成，供静态和动态回归共同使用。
- 动态回归只在存在公司内时间变化的样本上识别，因此需要保留 `special_year_ft` 在公司内有变动的企业。
- 输出结果时建议单独列出：
  - 样本单位
  - 样本量
  - 是否加权
  - 聚类维度
  - 系数、标准误、p 值
