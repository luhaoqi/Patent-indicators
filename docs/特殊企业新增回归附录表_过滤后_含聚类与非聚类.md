# 特殊企业新增回归附录表：过滤后样本，含 `cluster_firm` 与 `no_cluster`

本文档用于给论文制表提供底稿，统一汇总“过滤后样本”下的新增回归结果。

## 一、口径说明

- 样本口径：统一使用 `特殊企业_过滤部分单位`
- 窗口口径：
  - `window_1` 对应 `outputs/experiments/标题_摘要_ExactTime_window_1/stage2_exact/tables/特殊企业_过滤部分单位/`
  - `window_3` 对应 `outputs/experiments/标题_摘要_ExactTime_window_3/stage2_exact/tables/特殊企业_过滤部分单位/`
- 标准误版本：
  - `cluster_firm`：按公司聚类标准误，作为正式主版本
  - `no_cluster`：非聚类标准误，只作为对照版本
- 表格单元格式：`系数 + 显著性星号 / p 值`
- 星号规则：
  - `***`：`p < 0.01`
  - `**`：`p < 0.05`
  - `*`：`p < 0.1`

需要特别注意：

- `cluster_firm` 和 `no_cluster` 的点估计完全相同，差别只在标准误、`p` 值和显著性星号。
- 因此，正式论文正文建议优先报告 `cluster_firm`，`no_cluster` 更适合作为附录稳健性或“显著性敏感性”展示。
- 质量变量如果写成 `mean_*`，比较的是每个企业-年份样本的平均质量；如果写成专利层 `raw_q_pft`、`z_q_pft`、`topk_q_pft`，则每条观测是一件专利。
- 数量变量 `patent_count_ft`、`highq_count_ft`、`log_patent_count_ft`、`log_highq_count_ft` 比较的不是组内总和，而是每个企业-年份样本的专利件数或其对数，因此回归系数应理解为“平均每个企业-年份的数量差异”。
- 只有像 `tbl_abc_overall_compare.csv` 这类描述表中的 `total_patents`、`high_q_count` 才是组内总量，它们只能用来描述规模，不能作为“公平比较”或主回归结论。

## 二、符号说明

- 静态横截面 `S1-S7` 的核心解释变量是 `ever_special_f`
- 动态企业内 `D1-D7` 的核心解释变量是 `special_year_ft`
- A/B/C 分解 `G1-G7` 中：
  - `B-C`：曾被认定企业的非特殊年份，相对从未被认定企业
  - `A-B`：同一批曾被认定企业的特殊年份，相对其非特殊年份
  - `A-C`：特殊年份的特殊企业，相对从未被认定企业
- 在 A/B/C 表中，正系数表示前者高于后者，负系数表示前者低于后者

## 七、如何在论文中使用这些表

建议的正文与附录分工如下：

- 正文主表：
  - 只放 `cluster_firm`
  - 优先放 `S2`、`S3`、`D2`、`D3`、`G2`、`G3`
- 正文补充表：
  - 可放 `S5`、`S7`、`D5`、`D7`
- 附录表：
  - 放本文档中的完整结果
  - 同时列出 `cluster_firm` 与 `no_cluster`

从当前结果看，最值得在正文里强调的事实是：

- 过滤后样本下，质量主结果在 `cluster_firm` 版本中已经普遍转正
- `window_3` 的质量优势通常强于 `window_1`
- `no_cluster` 往往会进一步提高显著性，因此它更适合作为对照，而不是替代正式主结论
